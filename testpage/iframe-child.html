Iframe child content

IFRAME-1 The accessibility tree exposes an iframe as its own Document. A selection inside the child should be readable without touching the parent document.

IFRAME-2 Chromium keeps a separate text pattern for each frame. The probe must pick the pattern that currently owns the highlighted range.

IFRAME-3 Reading a word from a nested document is the same UIA call as reading it from the top-level page. The only difference is which element is selected as the target.

IFRAME-4 If the probe stops at the first Document in tree order, it will read the parent page and miss the iframe selection entirely.

IFRAME-5 A robust fallback scans the TextPattern-capable descendants and prefers the one with a non-empty selection.

IFRAME-6 This paragraph is extra material so the test always has at least five eligible blocks even if one paragraph is filtered out.
